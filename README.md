# Alors Lab Website

Static website for Alors Lab and Pixvera.

## GitHub Pages

Repository name:

`alorslab.github.io`

Deployment:

1. Open **Settings** in the GitHub repository.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/(root)` folder.
5. Save the settings.
